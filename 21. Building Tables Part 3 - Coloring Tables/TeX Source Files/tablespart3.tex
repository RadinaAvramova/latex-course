	\subsection{Using multirow with colortbl}
	\begin{enumerate}
		\item Insert the coloring command in each 
			row of the multirow cell.
		\item Place the multirow command in the last 
			row of the cell making\\ the number of rows
			negative.
	\end{enumerate}
